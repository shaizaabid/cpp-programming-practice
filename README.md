C++ Programming Practice

Overview

This repository contains 20 beginner-to-intermediate C++ programming exercises designed to develop fundamental programming and problem-solving skills.

The programs cover loops, arrays, conditional statements, searching, sorting, number logic, pattern printing, and menu-driven applications.

Topics Covered

- Loops: "for", "while", and "do-while"
- Arrays: One-dimensional and two-dimensional arrays
- Conditional Statements: "if", "else", and nested conditions
- Switch Statements: Menu-based program control
- Number Logic: Factorial, Fibonacci, prime numbers, and palindromes
- Searching and Sorting: Linear search and bubble sort
- Patterns: Number pyramid using nested loops
- Menu-Driven Programs: Calculator and medicine stock tracker

How to Run

1. Download or clone this repository.
2. Open any ".cpp" file in a C++ compiler or IDE.
3. Compile and execute the program.

Using g++:

g++ filename.cpp -o program
./program

Purpose

The purpose of this project is to practice fundamental C++ concepts through practical programming exercises and strengthen logical thinking and problem-solving abilities.
